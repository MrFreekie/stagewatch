# About Stagewatch

The **About Stagewatch** card is a small advert. It shows the name, one line ("Free, open-source
show monitoring.") and a QR code. Crew can scan the code with a phone to open the Stagewatch project
page, <https://github.com/MrFreekie/stagewatch>, which is also printed in small text under the code.

It is not on any dashboard by default. Your tech adds it under **Admin, User dashboards, Edit cards**.

Back to [Dashboard cards](README.md).

## Good to know

- It shows no show data and records nothing, so it looks the same all the time.
- The QR code is drawn on the dashboard itself. Nothing is fetched from the internet to show it, and
  it keeps showing if Stagewatch loses its connection. (Opening the link on a phone needs internet,
  of course.)
- The code sits on a white square in both the light and dark themes, so a phone can read it. It is
  larger on a wall screen.
- The code is drawn at the lowest error correction level (L), so it is compact. A scratched or glary screen may not scan.
- It can be set to **Half** width in the card list.
